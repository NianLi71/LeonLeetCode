list列表 · 也当栈用

最常用的容器。尾部增删很快，头部增删很慢，需要从头部弹出时换成 deque。

  • a[i]O(1)
  • append / pop()O(1)
  • insert(0, x) / pop(0)O(n)
  • x in aO(n)
  • sort()O(n log n)

grid = [[0] * n for _ in range(m)]   # m 行 n 列

二维数组不要写成 [[0] * n] * m，那样每一行是同一个列表，改一格整列都变。

deque双端队列 · from collections

两端增删都是 O(1)。BFS 的队列、滑动窗口的单调队列都用它。

  • append / popO(1)
  • appendleft / popleftO(1)
  • q[0] / q[-1]O(1)
  • q[i] 中间O(n)

基本操作

from collections import deque
q = deque()
q = deque([1, 2, 3])
q.append(x)        # 右端入
q.appendleft(x)    # 左端入
q.pop()            # 右端出
q.popleft()        # 左端出，O(1)；list.pop(0) 是 O(n)
q[0], q[-1]        # 看两端
deque(maxlen=3)    # 定长，满了自动挤掉另一端的元素

BFS 层序遍历 LC 102 二叉树的层序遍历

if not root:
    return []
res, q = [], deque([root])
while q:
    level = []
    for _ in range(len(q)):     # 当前这一层的节点数
        node = q.popleft()
        level.append(node.val)
        if node.left:
            q.append(node.left)
        if node.right:
            q.append(node.right)
    res.append(level)
return res

        nr, nc = r + dr, c + dc
        if (0 <= nr < m and 0 <= nc < n

单调队列 LC 239 滑动窗口最大值

q = deque()                 # 存下标，对应的值从大到小
res = []
for i, x in enumerate(nums):
    while q and nums[q[-1]] <= x:
        q.pop()             # 比 x 小的不可能再当最大值
    q.append(i)
    if q[0] <= i - k:       # 队头已经滑出窗口
        q.popleft()
    if i >= k - 1:

heapq堆 · 作用在普通 list 上

反复取最小值、Top K、合并有序序列、Dijkstra。默认是最小堆，要最大堆就把值取负。

  • heappushO(log n)
  • heappopO(log n)
  • h[0]O(1)
  • heapifyO(n)

最小堆

import heapq
h = []
heapq.heappush(h, x)
heapq.heappop(h)          # 弹出并返回最小值
h[0]                      # 看最小值，不弹出
heapq.heapify(nums)       # 把现有 list 原地变成堆，O(n)
heapq.heappushpop(h, x)   # 先 push 再 pop，比分开写快
heapq.nlargest(3, nums)   # 前 3 大；nsmallest 同理

最大堆：存相反数

h = []
for x in nums:
    heapq.heappush(h, -x)
biggest = -heapq.heappop(h)   # 取出来再取负
-h[0]                         # 看最大值

第 K 大：大小为 k 的最小堆 LC 215 数组中的第K个最大元素

h = []
for x in nums:
    heapq.heappush(h, x)
    if len(h) > k:
        heapq.heappop(h)      # 踢掉最小的
return h[0]                   # 堆里剩前 k 大，堆顶就是第 k 大

bisect二分查找 · 作用在有序 list 上

在有序数组里找插入位置。面试常要求手写二分，模板也放在这里。

  • bisect_left / bisect_rightO(log n)
  • insortO(n)

bisect 模块

import bisect
a = [1, 2, 2, 2, 5]          # 必须有序
bisect.bisect_left(a, 2)     # 1：第一个 >= 2 的位置
bisect.bisect_right(a, 2)    # 4：第一个 > 2 的位置
bisect.insort(a, 3)          # 插入并保持有序

i = bisect.bisect_left(a, x)
found = i < len(a) and a[i] == x    # 判断 x 是否存在

手写：找某个值 LC 704 二分查找

lo, hi = 0, len(nums) - 1     # 闭区间 [lo, hi]
while lo <= hi:
    mid = (lo + hi) // 2
    if nums[mid] == target:
        return mid
    if nums[mid] < target:
        lo = mid + 1
    else:
        hi = mid - 1
return -1

手写：找左边界 LC 35 搜索插入位置

lo, hi = 0, len(nums)         # 左闭右开 [lo, hi)
while lo < hi:
    mid = (lo + hi) // 2
    if nums[mid] < target:
        lo = mid + 1
    else:
        hi = mid
return lo                     # 第一个 >= target 的位置

结果和 bisect_left 一样。“找第一个满足条件的位置”的题都能套这个写法。

二叉树递归 LC 104 二叉树的最大深度

def maxDepth(self, root):
    if not root:              # 先处理空节点
        return 0
    return 1 + max(self.maxDepth(root.left),
                   self.maxDepth(root.right))

递归里更新全局答案 LC 543 二叉树的直径

def diameterOfBinaryTree(self, root):
    ans = 0
    def depth(node):
        nonlocal ans          # 要修改外层变量
        if not node:
            return 0
        l, r = depth(node.left), depth(node.right)
        ans = max(ans, l + r)
        return 1 + max(l, r)
    depth(root)
    return ans

单调栈 LC 739 每日温度

ans = [0] * len(t)
stack = []                    # 存下标，温度从大到小
for i, x in enumerate(t):
    while stack and t[stack[-1]] < x:
        j = stack.pop()       # j 等到了更高的温度
        ans[j] = i - j
    stack.append(i)
return ans

滑动窗口 LC 3 无重复字符的最长子串

last = {}                     # 字符 → 最近一次的下标
left = best = 0
for right, c in enumerate(s):
    if c in last and last[c] >= left:
        left = last[c] + 1    # 左边界跳过重复字符

类里递归忘了 self

✗ 错误
return maxDepth(root.left)    # NameError
✓ 正确
return self.maxDepth(root.left)

负数整除向下取整

-7 // 2         # 得到 -4

✓ 向零取整
int(-7 / 2)     # -3

遍历列表时删除元素

✗ 错误
for x in a:
    if x == 0:
        a.remove(x)     # 会跳过某些元素
✓ 正确
a = [x for x in a if x != 0]

可变对象当默认参数

✗ 错误
def f(path=[]):     # 所有调用共用这一个列表
    ...
✓ 正确
def f(path=None):
    if path is None:
        path = []
